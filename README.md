# WREN API Docs

The [OpenAPI 3.1](https://spec.openapis.org/oas/v3.1.0) specification for the [WREN](https://wren.aemwip.com) REST API.

Served interactively at [wren.aemwip.com/docs](https://wren.aemwip.com/docs) via [Scalar](https://scalar.com/).

## Files

- `openapi.yaml` — the full API spec covering documents, versions, labels, trees, schemas, binary assets, keys, permissions, org management, and the projects directory
